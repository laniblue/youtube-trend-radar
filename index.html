API 키 설정

유튜브 공식 무료 키가 필요해요. 한 번만 넣으면 돼요.
  1. 구글 클라우드 콘솔에 들어가서 새 프로젝트를 만들어요.
  2. 위 검색창에 YouTube Data API v3를 검색해서 사용을 눌러요.
  3. 왼쪽 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키를 눌러요.
  4. 키 제한에서 API 제한 → YouTube Data API v3만 골라요. 웹사이트 제한은 걸지 마세요. 파일로 열면 막혀요.
  5. 만든 키를 복사해서 위 칸에 붙여 넣어요.
무료 사용량은 하루 10,000이에요. 내 주제 검색이 하나에 100씩 들어서, 내 주제는 3시간에 한 번만 새로 검색해요. 키는 이 브라우저에만 저장되고, 이 파일을 다른 사람에게 줘도 키는 같이 가지 않아요.
